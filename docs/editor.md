# 𝑓OS 文本编辑器使用说明

[English](editor.en.md) | [简体中文](editor.md)

这是一个专为 **MicroPython** （如 ESP32、RP2040、PyBoard 等）编写的**纯文本编辑器**，提供基础编辑功能，适用于通过串口终端（PuTTY、minicom、screen 等）直接编辑设备上的文件。

## ✨ 功能特点

- 支持 ASCII 文本文件编辑、创建新文件
- 方向键移动光标、Home/End 快速跳转行首/行尾
- 插入/删除字符、回车换行、Tab 自动展开为 4 个空格
- `Ctrl+S` 保存文件，`Ctrl+Q` 退出编辑器
- 自动滚动、状态栏显示文件名、修改标记、光标位置
- 可自定义终端尺寸（宽、高）
- 退出时自动清屏，恢复原始终端状态

## 🚀 使用方法

### 导入并编辑文件

```python
import fos
fos.edit("boot.py")          # 默认 80x24 终端
# fos.edit("boot.py", width=100, height=30)   # 自定义尺寸
```

执行后，REPL 会进入编辑器界面，显示如下风格：

```
 boot.py   | Lines:4 | Pos:1,1 | Ctrl+S:Save Ctrl+Q:Quit
# 文件内容会打印出来 ...
```

## ⌨️ 快捷键与操作

| 按键               | 功能                               |
| ------------------ | ---------------------------------- |
| 方向键 ↑ ↓ ← →     | 移动光标                           |
| Home / End         | 跳转到行首 / 行末                  |
| 普通字符（含空格） | 插入字符                           |
| Backspace          | 删除光标前一个字符                 |
| Delete             | （尚未实现完整，可用删除后合并行） |
| Enter              | 换行                               |
| Tab                | 插入 4 个空格                      |
| **Ctrl+S**         | **保存文件**                       |
| **Ctrl+Q**         | **退出编辑器**                     |

## ⚠️ 重要提示

1. **终端流控**  
   若按下 `Ctrl+S` 后终端无响应（XON/XOFF 流控），请在**主机终端**执行一次：

   ```bash
   stty -ixon
   ```

   然后再连接 MicroPython 设备。

2. **字符集限制**  
   目前仅支持 ASCII 字符（英文、数字、基本符号），不支持中文、日文等 Unicode 字符。

3. **终端尺寸**  
   编辑器默认按 80 列 × 24 行显示，**必须与实际终端窗口尺寸一致**，否则光标位置会错位。如使用其他尺寸，需通过 `edit(filename, width=实际列数, height=实际行数)` 传入。

## 🔧 常见问题

- **问**：为什么状态栏不显示？  
  **答**：通常因为终端高度与 `height` 参数不匹配。请确认实际终端窗口行数（例如 PuTTY 中可调整窗口大小并查看配置里的行数），调用 `edit()` 时传入正确的 `height`。

- **问**：按退格键时删除了整行？  
  **答**：当光标位于行首时，退格键会合并当前行到上一行末尾，这是正常的编辑器行为。

- **问**：可以编辑超过 80 列的长行吗？  
  **答**：可以。超长行在显示上会被截断（末尾显示 `>`），但光标可以移动到被截断部分（编辑时按右方向键继续向右移动即可）。
